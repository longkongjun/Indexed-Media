# 首次安装发布包

本版本提供Core/Web单镜像、只读收件根及独立可写媒体目标的首次安装入口。
发布版本、源码、镜像digest、CI与迁移摘要见release.json；运行时构建版本保持git-SHA。

只接受全新实例目录，不支持从任何已有版本升级、接管或自动恢复；compatible_from为空，恢复类别为manual-required。
首次安装会初始化新的配置/密钥，健康检查就绪后仍需管理员在实际HTTPS入口完成初始化、登录、REST/SSE及目标NAS挂载验收。
安装失败保留实例数据和日志，禁止删除数据库重试或用旧库覆盖可能已有文件副作用的现场。
发布方必须对具体版本复核配置/迁移影响与验证记录；本文件不声明尚无实测证据的平台通过。
