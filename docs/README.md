# MediaFlow 实现文档

本目录保存 MediaFlow 的开发、代码实现、项目结构和部署实现文档。产品、方案、调研、架构基线、长期决策和路线图位于 [Indexed-wiki](https://github.com/longkongjun/Indexed-wiki)。

- `development/`：贡献流程、开发命令和实现约定。
- `operations/`：部署、备份、升级、反向代理和 NAS 实现说明。
- `architecture/project-structure.md`：代码仓库结构、模块边界和依赖方向。
- `architecture/archive-policy.md`：公开代码仓库的归档边界。

新的活跃文档文件名使用英文 ASCII kebab-case；章节索引使用 `README.md`。本仓库中的实现文档不得复制 Indexed-wiki 中持续维护的产品或业务正文。
