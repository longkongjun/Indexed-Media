# MediaFlow 路线图

## 已建立能力

- 本地优先、自托管的 Rust Core 基础。
- 管理员身份、会话和请求安全边界。
- 收件目录、扫描任务、连续发现和恢复。
- 确定性媒体识别、人工审核和正式 Catalog。
- 受能力限制的文件整理、日志和恢复。
- 下载器连接、任务观察和恢复。
- RSS、Webhook、下载完成映射与本地识别增强。
- Vue 管理 Web、版本化 API 客户端和测试夹具。

## 后续方向

1. 完善部署、升级、备份与 NAS 环境验证。
2. 补齐正式移动端和电视端浏览体验。
3. 强化大规模媒体库的性能、恢复和可观测性。
4. 扩展安全的来源自动化和本地模型能力。
5. 稳定公开 API、事件契约与集成文档。

路线图描述产品方向，不承诺具体发布日期。实际能力以源码、公开契约和验证结果为准。
