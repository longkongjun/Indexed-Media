# 交互模式 · 响应式三档（responsive-layouts）

> 版本：v1.0 ｜ 基准：web-experience §8 + token 断点（sm 48rem / md 64rem / lg 90rem）+ web-prototype 三段壳先例。
> 三档共享页面、路由、状态含义和恢复动作，只改变导航呈现与内容排列。

## 1. 三档定义

| 档 | 断点 | 导航 | 内容排列 |
|---|---|---|---|
| 宽屏 | ≥ md(64rem) | 固定文字侧栏 | 概览可双列；任务列表与详情可并排（lg 90rem 上限） |
| 中等 | sm–md | 侧栏收窄为图标列（title + aria-label 全量） | 单列为主；宽表横向滚动或降级列表 |
| 移动 | < sm(48rem) | 底部导航四项（概览/任务/媒体/更多） | 列表进完整详情页；表单单列 |

## 2. 降级规则

1. **表格 → 列表**：宽表（activity-table 类）在移动档降级为卡片列表（现状 `[data-wide-results]` 先例规范化：每张表声明移动降级形态）。
2. **并排 → 纵向**：任务列表+详情并排仅宽屏；中窄档详情为独立页（返回恢复列表上下文）。
3. **媒体墙**：三档均为流体网格，仅最小卡宽变化（移动 2 列起）。
4. **术语不变**：三档同术语、同状态名、同动作名（web-experience 原则 6）；禁止移动端缩写词。

## 3. 触控与指针

- 交互目标 ≥ touch-min（44px）三档一致；移动档无 hover 依赖（hover 反馈不得承载信息——等价触控反馈或直接省略）。
- 焦点环三档一致（键盘/辅助技术在触屏设备同样有效）。

## 4. 布局容器

- 表单容器 max-width 36rem；列表容器 64rem；宽屏内容区 lg 上限 + 居中；媒体墙全宽流体。
- 页头（h1 + 说明 + 主操作）三档同构，移动档主操作可入吸底操作栏（不悬浮遮挡列表）。

## 5. 平台差异

本模式定义 Web 三档；移动原生端（Compose/SwiftUI）天然处于"移动档"语义：底部导航、单列、44dp 触达、无 hover 依赖——组件规格的平台差异列已逐件对齐。
