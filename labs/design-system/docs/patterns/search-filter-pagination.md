# 交互模式 · 搜索、筛选与分页（search-filter-pagination）

> 版本：v1.0 ｜ 基准：table-list 规格 + CursorPager 先例 + web-experience"返回保留筛选与滚动位置"。

## 1. 三件套标准行为

| 元素 | 规则 |
|---|---|
| 搜索框 | 输入防抖 300ms 后查询；关键词写入 URL query；清空按钮；结果计数实时更新 |
| 筛选（tabs/select/checkbox） | 切换即查询；状态入 URL；组合筛选显示已选条件胶囊（可单个移除） |
| 分页（CursorPager） | 游标不透明；"上一页/下一页 + 已显示 N 项"；触底自动加载仅媒体墙（media-card），列表用显式按钮 |

## 2. 上下文保持（硬规则）

- 列表 → 详情 → 返回：筛选、分页游标、滚动位置三者全恢复（现状响应丢失问题的规范面）。
- 概览计数跳转 = 预置筛选的列表 URL（可分享、可刷新）。
- 浏览器后退/前进行为一致（URL query 为唯一状态源）。

## 3. 结果反馈

- 有结果：计数"共 N 项（已显示 M）"。
- 零结果（筛选导致）：Empty 态区分"筛选无匹配"（给清除筛选主操作）与"本就为空"（给配置引导）。
- 搜索进行中：Loading + stale 列表；不打断已读。

## 4. 等宽与截断

ID/路径列 `font-family-mono`；ID 显示前 8 位 + 省略号 + title 全量；路径列安全换行不截断词中。

## 5. 平台差异

| 维度 | Web | Compose / SwiftUI |
|---|---|---|
| 筛选入 URL | query 参数 | ViewModel 状态（返回恢复等价） |
| 搜索 | 防抖服务端查询 | 同语义 |
| 分页 | 游标 | 同语义（媒体墙触底加载） |
