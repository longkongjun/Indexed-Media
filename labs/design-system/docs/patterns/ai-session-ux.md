# 交互模式 · AI 会话交互（ai-session-ux）

> 版本：v1.0 ｜ 基准：dsh-collaboration §4 会话状态与脱敏 + AiSessionPanel 现状先例。
> 会话的入口、上下文携带、脱敏展示、跳转核对与六态消息行为。

## 1. 入口与上下文

| 入口 | 位置 | 携带上下文 |
|---|---|---|
| 全局侧栏面板 | 侧栏底部（现状先例）/ 移动端"更多"抽屉 | 无 |
| 页面唤起 | 任务/媒体页会话按钮 | `task_id` / `media_id` 注入首问 |
| 审批深链 | 会话内计划摘要 → Web 审批页 | `plan.version` |

首次问题模板："关于任务 #1042：…"——上下文可见可删（管理员能明确知道会话"看着"什么）。

## 2. 脱敏展示规则（与 session-message §3 同源，此处定交互面）

1. 输入不回显敏感值：粘贴的令牌/绝对路径在发送前 UI 提示"包含敏感信息，将不发送"（输入侧防呆，Core 侧脱敏为权威）。
2. 输出三级展示：相对路径（默认）/ 根目录 ID（路径不可相对化时）/ 完全隐藏（凭据、原始媒体内容）。
3. 错误展示：稳定错误码 + `required_action` 人话翻译；无堆栈、无内部 URL。
4. 会话历史不落敏感明文（Core 侧会话存储已保证；UI 不做本地明文缓存）。

## 3. 跳转核对（结论必须可核对）

- 凡引用实体（任务/计划/媒体/规则）→ 深链（text-link 样式，新页签或路由内跳转一致）。
- 引用块（mono 井）hover 显示完整安全标识 + 点击复制。
- 核对优先级：用户点链接看到的 = Core 权威页面；会话内容只是摘要（页面标注"AI 摘要，以详情页为准"于面板头部说明文字）。

## 4. 六态消息行为

| 态 | 消息形态 | 后续 |
|---|---|---|
| Loading | 流式打点，输入禁用 | 完成自动滚到底部 |
| Empty | 无结果 + 建议改写 | 提供改写建议按钮 |
| Error | 对象+原因+补救 | 补救链接 |
| Offline | "AI 不可达，先用页面功能" | 面板保留，后台静默重连（指数退避） |
| Conflict | 依据/版本冲突 | "重新查询"按钮 |
| Partial | 完成+待办 | 待办深链 |

## 5. 开关与降级

- 设置 → DSH 连接：状态/地址/令牌管理/启用开关；关闭后会话入口整体消失，全部 Web 功能不受影响（验收要点）。
- DSH 超时/停机/升级/无效输出：不改变 Core 结果与已入库资源（A4 降级矩阵）；会话只呈现 Offline/Error 消息，不产生任何任务副作用。

## 6. 家庭成员会话（未来）

权限严格小于管理者：只读消费数据（找片/推荐解释），不触发文件操作或配置变更——UI 层无审批入口、无写操作词汇。
