# 任务时间线（task-timeline）

> 版本：v1.0 ｜ 状态：定稿 ｜ 来源：新功能规格（任务详情"阶段时间线"，web-experience §4 任务详情必显项）
> 展示任务"发现→识别→计划→文件操作→NFO→完成"的阶段推进、当前所处阶段与每阶段的真实结果。

## 1. 解剖

```text
┌ task-timeline ────────────────────────────────────────────┐
│ ●─ 发现      已完成 · 14:02  [展开: 发现明细/来源]           │
│ ●─ 识别      已完成 · 14:03  [展开: 候选与依据]              │
│ ◉─ 文件操作  进行中 · 已完成 2/4 [展开: plan-preview 子集]   │
│ ○─ NFO       未开始                                          │
│ ○─ 完成      未开始                                          │
│ ⚠（可选）失败/暂停节点：失败阶段 + 原因 + 未执行动作 + 恢复动作│
└───────────────────────────────────────────────────────────┘
```

- 节点符：`●` 完成（success）· `◉` 进行中（info + 旋转）· `○` 未开始（text-muted）· `⚠` 失败/暂停（warning/danger）——形状+文字双编码。
- 连接线：完成段 `color-border-default`；未到段 `color-border-subtle`（装饰级）。
- 阶段名 + 状态文字 + 时间（`font-size-sm`，`color-text-secondary`）；展开区为每阶段事实（等宽路径/规则标识）。

## 2. 状态 × 变体矩阵

变体：`detail`（任务详情完整版）/ `compact`（列表行内迷你：仅节点符序列 + 当前阶段名）。

| 任务状态 | 时间线形态 | 恢复动作（唯一） |
|---|---|---|
| 进行中 | ◉ 当前阶段 | 取消（secondary-danger，需确认） |
| 待确认 | 识别节点 ◉ 展开 | 选择候选/转通用视频（跳 review 流） |
| 冲突 | 计划节点 ⚠ | 修正规则或目标（跳表单） |
| 失败 | 失败阶段 ⚠ + 已产生结果/未执行动作两组清单 | 从安全检查点重试 |
| 部分成功 | 完成节点 ◐ + 已完成/未完成分组 | 只重试未完成步骤 |
| 完成 | 全 ● + 结果摘要（Success 确认） | — |

双主题：节点符色取 state-*/text token 双值；展开区底 sunken 双值——均成立。

## 3. 行为与交互

- 展开区手风琴：同时只展开一个阶段；展开态保留在返回导航后（列表返回保留上下文原则）。
- 文件操作阶段展开 = 该任务 plan 的已执行子集（复用 plan-preview 行样式，只读 + 每行结果标记 ✓/✗/未执行）。
- 失败/部分成功时**默认展开**问题节点（直达恢复动作，不藏一层）。
- 时间显示相对时间 + hover 绝对时间（title）；不做时间轴动画。

## 4. 可访问性

- 键盘：节点 Tab 可达（button，展开/收起）；左右箭头在节点间移动（roving tabindex）；恢复动作在展开区内正常 Tab 序。
- 焦点：展开/收起后焦点保持在节点按钮；默认展开的问题节点容器 `tabindex=-1` 并聚焦（读屏直达原因）。
- ARIA：容器 `role=list`，节点 `role=listitem` 内 button `aria-expanded`；进行中节点 `aria-current=step`；失败节点文字入 `role=status` 播报。
- 对比度：阶段名/状态文字 text-secondary × surface 全过；节点符色为非文本但**有大号形状+文字双编码**，颜色不承担唯一识别（符合"状态不单靠颜色"）。
- 边框分级：连接线为装饰级（D-0006）。

## 5. 主题表现

不敏感（全部 token 双值）；展开区等宽路径块遵循 session-message 同款"井底"暗色规则。

## 6. 用法与反例

✅ 部分成功任务：文件操作节点展开可见"已完成 2 项 / 未完成 2 项"分组，主操作只有"重试未完成步骤"。
✅ compact 变体在任务列表行：`●●◉○○` + "文件操作中"。
❌ 重试按钮出现在多个阶段节点（重试只属于失败/部分成功态的唯一主操作）。
❌ 隐藏失败阶段的已产生结果（管理员须知道哪些文件已动过）。

## 7. 平台差异

| 维度 | Web | Compose（M3） | SwiftUI |
|---|---|---|---|
| 实现 | ol + button 节点 | `LazyColumn` + 自定义节点 | `VStack` + DisclosureGroup |
| compact | 行内 span 序列 | `Row` + Canvas 节点 | `HStack` |
| 恢复动作 | 跳对应页面 | 跳对应 Screen（M5 第一批只读：查看+取消入口视权限） | 同左 |
